# A--Computers-Store
My third project in HTML &amp; CSS: A PC builds showcase
اسم المشروع: A+ Computers
وصف المشروع:
صفحة ويب بسيطة (Static Webpage) مصممة لعرض تجميعات أجهزة الكمبيوتر (PC Builds) مع تفاصيل ومواصفات كل جهاز. هذا المشروع هو تطبيق عملي لأساسيات تطوير واجهات الويب (Front-End) والتدرب على بناء هيكل الصفحة وتنسيقها.
التقنيات المستخدمة:
 HTML
 CSS
ملاحظات تقنية حول بناء المشروع:
 تم الاعتماد على خاصية ⁠float⁠ في CSS لترتيب الكروت (Cards) وتخطيط الصفحة.

Project Name: A+ Computers
Description:
A static webpage designed to showcase custom PC builds along with their detailed hardware specifications. This project serves as a practical application of front-end web development fundamentals, focusing on page structure and styling.
Technologies Used:
 HTML
 CSS
Technical Notes:
 The layout and card alignment were implemented using the CSS ⁠float⁠ property.
